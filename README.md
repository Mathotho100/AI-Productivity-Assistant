# CareerBoost AI Assistant

Prompt for Building CareerBoost AI

Build an AI-powered workplace productivity assistant called CareerBoost AI with a modern, clean, and mobile-responsive user interface. The assistant includes these core features:

1) Smart Email Generator

Functionality: Generate professional emails with customizable tone and audience.

Tone Selector: Options include Formal, Informal, and Persuasive.

Audience Selector: Options include Client, Manager, and Team.

Input: User types key points or a brief summary of the email purpose.

Output: A complete email draft that matches the selected tone and audience style.

Feature: Real-time live preview of the generated email content as selections or input change.

2) Meeting Notes Summarizer

Functionality: Input raw meeting notes or transcript text.

Output: A concise summary highlighting:

Key Points discussed

Decisions Made

Action Items with assigned responsible parties (if available)

Deadlines or timelines mentioned

Feature: Live preview while typing or pasting notes.

3) AI Task Planner

Functionality: User inputs tasks and deadlines.

The planner creates daily, weekly, or custom time range plans.

Prioritizes tasks based on urgency, approaching deadlines, and task importance.

Output: A clear, organized schedule or checklist segmented by day with prioritized tasks.

Feature: Allows live editing and updates with immediate rescheduling.

User Interface Requirements:

Modern, intuitive design with easy navigation between features.

Responsive layout adapting smoothly for desktop and mobile screens.

Smooth transitions, clear font hierarchy, and accessible colors.

Each main feature panel includes input area on left/top and live preview on right/below.

Footer Disclaimer

A persistent footer with text:
"AI outputs may contain bias - please validate."

Styled subtly but clearly visible on all screens.
